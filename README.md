## 👨‍💻 Sobre mim

Olá! Sou Marcos Henrique, desenvolvedor de software apaixonado por tecnologia, programação e inovação.

Atualmente, meu foco está no desenvolvimento de aplicações utilizando **C# e .NET no Backend** e **React no Frontend**.

Tenho interesse em arquitetura de software, desenvolvimento de APIs, integração entre sistemas, banco de dados e infraestrutura.

Gosto de transformar problemas reais em soluções tecnológicas, sempre buscando aprimorar meus conhecimentos e desenvolver aplicações cada vez melhores.

* 💻 Backend: C# e .NET
* ⚛️ Frontend: React, JavaScript e TypeScript
* 🗄️ Banco de dados: SQL Server
* 🚀 Interesse em arquitetura de software e desenvolvimento de sistemas
* 📚 Sempre aprendendo e explorando novas tecnologias.
